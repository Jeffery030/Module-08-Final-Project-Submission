# TMDB Movie Explorer

The TMDB Movie Explorer is an engaging mobile application built using React Native and Expo, designed to provide users with a seamless movie browsing experience.
  Features
Movie Information Retrieval: The application retrieves comprehensive movie information from the TMDB (The Movie Database) REST API, ensuring users have access to the latest details.
Popular Movies Display: Users can easily browse a curated list of popular movies, complete with key details and engaging visuals to enhance their movie selection experience.
Search Functionality: The app includes a robust search feature that allows users to quickly find their favorite movies by title, genre, or any other relevant criteria.
Movie Details Screen: When a user clicks on a movie, they are taken to an immersive movie details screen. This screen provides an in-depth look at the film, including cast details, ratings, synopsis, and more.
React Navigation Integration: The application uses React Navigation to provide a smooth and intuitive navigation experience, allowing users to move between different screens effortlessly. 
Responsive User Interface: Built with Flexbox, the user interface is designed to be responsive and visually appealing, ensuring that it looks great on devices of all sizes.
Loading and Error Handling: To enhance user experience, the app includes loading indicators and error messages, providing feedback during data retrieval and helping users navigate any potential issues.
 
 Screens
1. Home Screen: The main hub where users can discover popular movies and access the search functionality.
2. Search Screen: A dedicated screen for users to input queries and find specific movies.
3. Movie Details Screen: A detailed view that presents all information related to a selected movie.
  Technologies
- React Native: A popular framework for building native apps using React.
- Expo: A set of tools and services that streamline the development of React Native applications.
- JavaScript: The primary programming language used in the development of the app, enabling interactive and functional features.
- TMDB API:  The external API that provides extensive movie data used within the application.
- React Navigation: A library that facilitates easy navigation between different screens in the application.
